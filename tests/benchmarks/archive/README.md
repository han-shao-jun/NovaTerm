# 历史基准归档

本目录按主题保存历史报告、对应版本的复现与分析脚本、源码快照及必要环境说明。

- `lz4/`：历史压缩、GUI 滚动、调参及性能审查归档。
- `mcp-history/`：历史录制基线与审查修复归档。

各主题下保留原日期目录，报告与其脚本、快照和本地输入相邻存放。
可重新运行生成的编译/测试日志、逐进程 JSON、矩阵、trace、验证/汇总 JSON、
重复表格和临时状态标记均已删除。失败结论和未验收范围仍保留在对应报告中。

2026-10-21 清理了 243 个 `.log`、14 个编译/测试 `.txt` 输出，以及全部 200 个
JSON（约 60.8 MiB）；另移除重复生成的 `tables.md` 和已释放的显示保护标记。
报告中的历史数值没有改动；重跑会生成新样本，不能还原原先运行的逐事件时间。

优先使用 `tests/benchmarks/history/lz4/README.md` 中的生产基准入口，结果写到 `build/`
下的新目录。各历史子目录中的归档分析脚本需要先准备相应版本、参数和目录布局的重跑输入；
它们不再附带原始数据，不能直接用于验证当前工作树。保留各历史归档内部的文件结构。脚本的相邻输入及生成结果放在对应子目录，或使用其命令行参数指定目录。测试输出 txt 仅保留本地，不纳入 Git；环境说明 `cpu-topology.txt` 继续保留。
