# 实施审查记录

实现遵循 effective-cpp 的先测量、RAII、显式所有权及受保护并发状态约束。

只读代码复审覆盖 LineLayout 前瞻、Renderer 排队准备、不可变快照/句柄、
GUI 生命周期及真实 GPU 自测。审查未运行编译或采样，避免与测量争用机器。

首轮指出逐事件调用 LineLayout::viewport 会重复完整折行超长 Raw 逻辑行，
绕过帧调度的合并。最终改为每事件轮次一个 Qt queued 回调，读取最新目标，
使用已有显示布局及块索引，每个相交块仅查一次 CacheOnly，不重新折行。

复审确认首/尾可见范围、部分相交首块、尾块包含关系、布局改宽/淘汰兜底与
对象销毁时回调撤销；未发现新的高置信问题。现有队列、cache/pin 和临时额度
均沿用原配置，已开始的后台单块任务未增加抢占取消机制。

通知过滤原型曾一次完整负载超时，后续诊断复跑通过，未确定根因；最终撤回
过滤并恢复原 historyDataReady 接线。失败日志与 rejected-gating-and-wrapping.patch
只用于追溯，不能计为最终版本的性能或稳定性成绩。

GPU 自测保留 Pending 不更新旧完成标记和增量帧先执行的交错。为稳定触发
Pending，夹具在生产读取上下文的任务回调边界暂缓交付，再放行真实解码和通知。
新增提前准备断言在第一次冷读回调内记录 handoff 次数；早期在事件循环返回后
读取该次数，可能把随后正常定时器交付计入前序，已修正取样时刻。

CPU 门槛必须区分原完整不绑核矩阵和补充的同类核心控制，不能以 CPU 控制
样本覆盖原矩阵中 mixed 相对 OFF 超过 10% 的事实。最终数值和范围见 README。
