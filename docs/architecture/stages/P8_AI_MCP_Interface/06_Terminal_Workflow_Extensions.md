## 1. 最小交付范围

| 差距 | 补齐方案 | 边界 |
| --- | --- | --- |
| 缓存不易回查 | 屏幕、当前尾部书签、保留起点和精确位置续读 | 复用终端缓存，不新建日志数据库 |
| 等待指定结果需反复往返 | 有界字面文本等待，明确日志或屏幕来源 | 不迁入脚本引擎或开放任意正则 |

| 二进制部署文件缺少入口 | 已授权 SSH/SFTP 单文件上传、下载、进度和取消 | 不自动烧录、重启或执行下载文件 |

## 2. 指定文本等待

输入包含明确的 Session/epoch、读取来源、条件文本、起点和等待期限。它是只读用例，不发送探测字符，不获得输入权。

| 来源 | 起点 | 匹配范围 |
| --- | --- | --- |
| 日志 | 调用方日志游标；未提供时以明确返回的当前尾部建立基线 | 只扫描该位置之后仍保留的文本，不能用上轮 PASS 立即满足本轮等待 |
| 当前屏幕 | 显式选择当前快照或基线之后变化的快照 | 用于未换行提示、U-Boot、TUI；返回屏幕 revision 与捕获时间，不伪装日志位置 |

首版支持字面匹配、明确大小写选项和有界的候选列表；any/all 的精确枚举在 B0 冻结。all 只表示范围内均出现过，不证明顺序。首版不开放任意正则，复杂分析留给外部 Agent。

结果区分 matched、timeout、cancelled、gap、invalidated 和扫描预算耗尽；返回命中的条件、位置/屏幕版本、有界上下文和下一观察位置。匹配到 PASS 只证明该文本出现，不自动把任务或功能测试判为成功。

日志匹配跨页、跨 chunk 和 UTF-8 分段保留有界尾部；不删除换行后拼接无关文本。匹配后的进度按明确消费边界推进，不跳过未返回的后续日志。扫描预算耗尽有可续扫的位置和匹配状态，不从断点任意重置匹配器；状态有 TTL 和总量上限，失效明确拒绝。

等待前、唤醒时、交付前均复核授权和绑定。清空、缓存淘汰、重连或撤权返回明确失效/缺口，不能静默换起点。屏幕匹配不跨屏幕版本拼接文字。超时返回有效进度，但不代表错误不存在。

单次等待不超过现有 30 秒上限；长等待由调用方续接。候选数、条件长度、扫描字节、每轮 CPU 工作量和每客户端/全局并发都必须有上限。取消等待不发送 Ctrl+C，不停止远端命令。

## 3. 长任务入口

| 操作 | 输入与行为 | 输出事实 |
| --- | --- | --- |
| 启动 | 目标、最新输入条件、operationId、命令/动作、执行模式及期限，经既有授权/仲裁提交 | taskId、关联 executionId（若有）、受理/提交状态、起始日志位置 |
| 查询 | taskId、可选日志游标；不再次执行 | 状态、完成证据、退出码（可空）、有界新增输出/续读位置、建议查询间隔 |
| 请求停止 | taskId、幂等操作 ID、明确停止意图；核对当前执行与控制代际 | 已请求停止、已确认终止或结果未知，不把返回成功等同于远端已停 |

taskId 绑定可信客户端与目标，不等于 RPC ID、日志游标或 PID。启动精确重试返回同一任务；同 ID 不同参数拒绝。查询不得延长输入权限或自动抢回人工控制，停止不得影响别的客户端或新执行。

CommandRuntime/Session Controller 继续拥有执行事实；新增异步任务索引只保存关联和有界结果，不复制超时、取消、输入、完成解析状态机。输出引用现有缓存，清空/淘汰后任务仍可返回执行事实和日志缺口；不能为任务无限保留旧块。

状态至少区分受理、运行、停止请求和终态；completed、exitCode、terminationConfirmed、evidenceKind 分别解释。UART 静默等待结束没有可靠完成证据时保留未验证/未知，不能合成为 exitCode=0。超出执行期限按现有取消与未知保护收口。

### 传输差异

- SSH 优先操作现有可见终端，保留 cwd/env。独立 exec 若另行支持，必须显式声明执行模式，不能静默改成隔离子 Shell。
- UART 支持获准原始输入后的异步观察，不要求 POSIX 包装；是否可验证完成、是否可请求中断独立报告。不能照搬 Netcatty 拒绝 Serial 后台任务的限制，也不能假装 Serial 有可靠退出码。
- 发现结果分别表达可启动、可观察、完成证据类型、可停止及不可用原因，而不是单个 supported=true。
- Ctrl+C 只在原任务/目标/控制代际仍匹配且明确获准时发送。人工接管后，旧停止请求不得打断人的新命令；无可靠停止能力时如实报告。

新异步启动被应用受理后，短 RPC 断流不删除任务或重复提交；不改写旧同步工具的取消语义。调用方可通过原 operationId 查询受理结果。首版不跨应用重启恢复执行，失去记录时报告不可用/未知，不自动重跑。活动任务、保留结果、日志引用与并发均有硬预算。

## 4. SSH/SFTP 单文件传输

2026-10-27 第一子批先提供独立文件授权与只读 `novaterm_list_file_resources`，当前二十二工具；精确字段与预算见[02](02_Current_MCP_Contract.md#b3b-文件传输第一子批独立文件授权目录2026-10-27)，实现及验证见[记录](records/B3b_File_Resources_2026-10-27.md)。它不执行文件I/O，不代替以下上传/下载、路径安全和发布事务。

复用已有 SSH/SFTP 与文件发布边界；远端凭据留在本机通路中。文件内容不写入终端，也不放进大段 MCP JSON。UART 首版仍只做观察/交互，已有 X/Y/ZMODEM UI 不等于 MCP 传输已经开放。

输入明确 Session/epoch、方向、本地授权资源引用及相对路径、远端路径、覆盖策略和 operationId。读取终端不授予文件权限；本地读/写、远端读/写分别授权。用户可以预先选择构建输出/下载目录，Agent 不因此得到任意本机路径访问能力。

实现必须复核路径、符号链接、目标身份和检查后的路径替换；不能仅做字符串前缀比较。默认不覆盖已存在文件；覆盖需要显式意图和写权限。仅处理普通文件，不把设备节点或块设备作为固件文件目标。

通过 transferId 查询进度和请求取消，状态由已有传输 owner 管理。固定缓冲、并发数、最大文件大小、临时空间、无进度期限和总体期限必须有具体有限默认值，在 B0 根据复用后端冻结，不能采用无限值。

精确重试返回已有任务，不重复覆盖。临时文件在授权目标范围内创建，提交完成才报告文件发布；不支持原子提交时明确声明能力和风险，不能把普通写入称为原子发布。取消/断连返回临时文件处置和发布是否未知，只清理本次拥有的文件。

区分传输字节数、目标已发布、大小校验和内容 hash 验证。只有实际验证内容 hash 才标记内容已验证；不为取 hash 自动向未知终端发送命令。文件成功发布不自动执行 chmod、insmod、重启或烧录，这些是 Agent 后续的独立获准操作。

传输不能阻塞终端观察或在 GUI 线程进行文件 I/O。对同一路径发布使用既有互斥/事务，不与现有脚本发布互相覆盖。

## 5. 已保存目标连接管理

第一子批实现 `novaterm_list_targets` 和本机逐客户端目录共享。第二子批已追加 `novaterm_open_target`、`novaterm_query_target`，须另勾选允许打开，按配置版本和operationId受理；查询返回实际会话/epoch与连接状态。availability=saved_configuration本身仍不代表在线。安全关闭及新会话预授权已追加，当前新会话权限默认关闭；本机可预先选择读取/完整输入/清空规则，见[预授权记录](records/B3b_New_Session_Sharing_2026-10-27.md)。

只列出本机用户明确共享的保存目标；返回 targetId、显示名、传输类型、获准端点摘要、配置版本和可用状态，不返回密码/私钥。目标目录与活动 Session 目录分开，模型不能通过工具修改 host、port、波特率、认证或 Profile。

| 操作 | 约束 |
| --- | --- |
| 列出目标 | 只列获准项，标明当前可复用会话；端点信息按共享范围披露 |
| 打开/复用 | targetId、配置版本、operationId；优先复用匹配的 connected/connecting 会话，返回 created/reused 与连接状态 |
| 查询连接 | 返回实际 sessionId/epoch、connecting/running/failed、需要用户处理的认证或主机密钥步骤 |
| 关闭 | 默认只允许关闭本客户端本次明确创建、未被人工接管且无活动任务的会话；不得清理复用的人类会话 |

打开权限不自动授予读取/输入。用户可预先给保存目标配置明确的共享规则，新会话依该规则重新核验并绑定 grant；不能复制旧连接/其他客户端的临时授权。

保持现有“1 TerminalView 拥有 1 TerminalSession”。应用用例通过目标/连接工厂窄端口请求，已有组合根创建可见会话；不让 HTTP 线程构造 UI，不新建后台 SessionManager。

相同 operationId 精确重试不得新开标签；配置变化、串口占用、认证待处理和应用重启分别返回。不得通过关闭人类串口会话来腾端口。断线后优先查询既有重连状态；不自动循环创建连接或猜测新地址。

认证和 SSH 主机密钥决策仍在本机 UI，Agent 不填写秘密。关闭时重新核对 owner、控制代际、执行和传输状态；busy/unknown 明确拒绝。强制关闭不作为默认清理操作，未来如开放需另一次明确授权。

## 6. 统一 Agent 使用指引

两代握手 instructions、工具描述和用户说明维护同一行为规则，并由契约测试检查语义一致：

1. 本地编辑/编译用 Agent 本地工具，目标板操作用显式 NovaTerm Session，不能混淆两个 Shell。
2. 先列目标/会话并观察，再输入；无会话时仅打开已获准保存目标。
3. 短交互用输入/命令，长任务用异步入口；工具未实现时不推荐虚构调用。
4. 日志游标、当前屏幕、固定 capture 补读各有用途；缺口不证明没有错误。
5. 文本匹配和 UART 静默都不自动证明成功；实际固件标识与功能判据另行核对。
6. 清空、传输、打开和执行分别授权；未知结果不换 ID 自动重放，不换工具绕过拒绝。
