“当前可测”表示已具备产品入口；需要相应设备、授权或环境的项目可标记阻塞，并写明缺少条件。通过、失败、阻塞、不适用分别记录，不把未测项计为通过；不适用项说明理由。每项至少保存工具响应和对应设备/终端证据，不能只凭界面提示或工具返回 ok 判定。
