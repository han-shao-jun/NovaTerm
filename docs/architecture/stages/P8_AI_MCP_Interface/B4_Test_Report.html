交互、等待与任务（本机预验，SSH/UART分别记账）

新就绪连接默认允许完整输入，仍核对当前权限和输入就绪；清空权限独立。旧脚本工具已退役。动作、行结束符和停止操作按第1节范围。

可用的有限长任务样本：在已获准的 POSIX Shell 中输出本轮BEGIN，等待35秒，再输出本轮END。实际命令及RUN_ID在执行前填入记录；任务停用样本不得依赖重启、烧录或破坏性写入。

当前可测：UART

先由用户指定端口和完整串口参数，确认不会占用其他程序的生产串口。UART初测只读；后续输入和重启分别按第1节授权。

当前可测：SFTP上传/下载与UART/ZMODEM发送

下列为步骤模板，执行状态见总账。先明确设备、直接路径、接收目录/策略和允许的后续命令；SFTP上传、下载和UART发送分别验收。SFTP上传/下载已有阶段软件验证，显式覆盖本阶段Windows软件回归已完成，B4仍待用户验收；实际可测范围以运行版本为准。

SFTP下载

使用用户明确授权的SSH测试目标、远端源目录与本地写入目录；本地目标父目录须已存在。下载复用原SFTP连接，不要求远端hardlink扩展。当前安全本地Writer支持Windows/Linux，Linux需支持的本地文件系统与renameat2；macOS未实现；远端目录属主与管理员须可信，不将SFTPv3路径检查视为抵抗同账号恶意换路径的保证。

UART/ZMODEM发送

只在明确许可的接收端与目录执行，接收程序独立准备。Windows/Linux安全Reader支持最多64 MiB；同AI输入控制由发送工具自动衔接，不要求手动release，不自动发送rz或改串口配置。

SFTP显式覆盖

仅使用其他写入者可信的测试目录；直接路径仍经过当前身份/会话/安全文件准入，上传按X组确认。true授权目标路径替换，不是CAS；最后复核与rename之间有竞争窗口。本地pinPath不检查ACL/owner，不能把目录句柄固定当作已强制建立可信写入者条件。
