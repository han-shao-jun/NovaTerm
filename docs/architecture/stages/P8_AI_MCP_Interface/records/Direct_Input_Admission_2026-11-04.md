# 终端直接准入改造（2026-11-04，工作区增量）

## 目标与实现

用户明确要求采用 Netcatty 项目的调用方式，从 NovaTerm 侧解决客户端审批期间输入令牌过期的问题。Netcatty 的终端执行/启动只要求目标与命令，不要求审批前取得短期输入令牌；本轮借鉴该调用模式，未修改 Netcatty 或 Codex。

`novaterm_interact_terminal`、`novaterm_start_task`、`novaterm_request_elevation` 的 `inputToken` 改为可选。新 instructions 与示例默认省略它，仍保留明确的 sessionId、epoch、operationId 和动作/提权参数。显式提供非空旧令牌时严格沿用签名、期限、身份与序号检查；空字符串、null、错误类型拒绝，不将失效令牌悄悄降级为直接模式。已有 read_context 的令牌输出保持兼容。

直接请求到达 Service 后、进入调度队列前，记录内部签名保护凭据。该凭据不暴露成新 wire 参数，原样传到最终输入准入，不在排队结束时重新生成。权限与连接绑定、人工/控制/输入序号变化、缓存清空、会话换代、忙碌与命令上下文继续校验。凭据是在客户端审批之后才产生，因此客户端审批等待不会消耗它的有效期；服务端队列和任务期限仍有界。

任务身份 hash 使用原始请求，不纳入后续生成的内部凭据。同 ID 精确重试先返回既有事实；相同 ID 改动作或跨接口改作另一笔写入仍拒绝。未知结果仍须查询原操作，不能换 ID 自动重发。提权适配器的可用性限制没有改变。

## 必须明确的语义变化

新路径不再绑定客户端审批前的观察。它不能仅凭旧观察发现请求到达之前的人工作业或普通输出变化；调用方仍应核对终端和目标，不能假设审批期间终端一直空闲。普通 UART 缺少可信完成事件的限制也仍存在。请求到达后的排队保护，不应表述成与原观察绑定完全等价。

需要旧观察绑定时，可以显式提供有效 inputToken。新模式不是忽略一个已过期令牌，而是调用方明确省略旧凭据、改用到达后准入的协议路径。无须关闭 Codex 逐次审批或修改永久允许配置。

## 审查与回归

独立只读代理先指出应把同一 receipt guard 传到最终准入，且不能在业务判重之前用过时的队列序号误拒绝精确重试；实现按此处理。随后发现任务入口先 sweep() 再使用借用参数，过期释放引发同步回调时调用方参数可能失效。TerminalTasks 与 TerminalInteraction 公共入口改为按值持有请求、上下文、调用身份及内部凭据，再进入实现。

新增确定性回归在同步释放回调中修改调用方请求，旧实现误读成另一个任务而失败，修复后仍处理原请求。此为参数快照行为证据，不冒称本轮运行了 ASan 或独立复现堆 UAF。代理复核按值传参与最终 guard/任务身份逻辑，未发现剩余高可信问题。

## 生效与尚未验证范围

必须运行新构建的 NovaTerm，并让 Codex 重新连接、重新获取工具目录与 instructions。旧客户端会话可能仍认为 inputToken 必填，继续使用旧路径时也仍可能因旧令牌过期而拒绝。

本轮已完成实现、构建和软件回归，尚未在重启后的真实串口/SSH实例上验收新直接模式。此前实际采集与40秒令牌测试均属于旧运行实例，不能用作本次新协议的实机通过证据。
