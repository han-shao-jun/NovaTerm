# 直接路径传输与 MCP 使用精简

用户要求取消先选文件夹/文件共享的前置授权，提示词指定路径，在 AI 对话中确认上传；NovaTerm 收到工具调用直接执行。继续取消同类重复操作。

## 已选方案

确认发生在 AI 对话中，用户进一步明确要求工具强制两步调用：首次上传返回 confirmation_required 及规范源/目标路径和一次性确认凭据，外部 Agent 向用户确认后，以相同 operationId/参数携带确认凭据再次调用；拒绝则不上传。不新增 NovaTerm 弹窗，也不要求客户端实现 elicitation。服务端验证确认凭据与操作参数，不能验证 Agent 是否真实展示过自然语言问题。

同一规范源文件路径、目标端点/位置、协议及覆盖意图记忆于本机，后续相同操作免重复确认；目标/路径/覆盖变化重新确认。记忆按路径而非内容 hash，便于同路径反复构建/上传。提供清除记忆入口。待确认记录有界且短期有效，绑定原身份/连接代际，重置令牌/断连/取消不会复活旧操作。

## 行为

- SSH 上传/下载直接传 `localPath`、`remotePath`、当前 `sessionId/epoch`、`operationId`，可选 `overwrite=false`。
- UART 发送直接传 `localPath`、当前 `sessionId/epoch`、`operationId`，`remoteName` 省略时取源文件名。
- 取消本地目录读写、远端目录读写及串口目标预授权；移除设置中的文件授权入口和两个授权目录工具。AI 使用已有会话目录定位连接，用户不用手填内部 ID。
- 原 SFTP owner 按需准备连接并等待就绪；不要求用户先打开文件面板。UART 发送衔接本统一主体的空闲输入控制，保留原协议 owner 与实际传输互斥。
- 仍绑定原会话/连接代际、统一身份和精确重试参数。断开/令牌重置/取消使在途任务失效；重试不重复发送，已发布事实保留。
- 保持现有固定句柄 I/O、路径校验、大小/分块/时间预算、默认不覆盖和原子发布。直接路径指 NovaTerm 所在机器的路径。
- 对旧授权参数明确拒绝，避免新旧语义混用。已删除功能的历史记录/fixture保留为历史证据。

## 范围与约束

Qt/C++ 原架构，不新增协议执行器或第三方依赖；复用现有 SftpSession、SerialFileTransferController、LocalFileReader/Writer。Windows 本机验证；Linux Reader 源码保持，Linux Writer/macOS 缺口如实说明。无需真实设备，不自动提交或推送。

用户已确认一并取消历史录制逐条共享；统一 MCP 接入启用后即可读取已有录制，录制启动不自动化。独立文件导入仍是创建可搜索资源的操作，不需要额外逐条授权。
