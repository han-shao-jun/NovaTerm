# MCP 接入与旧命令通路清理

用户已于2026-10-29批准此前建议的范围：退役旧命令通路及对应UI；保留新终端交互、文件传输、会话管理和历史录制；客户端管理移入次级入口。

## 方案与边界

选择删除旧接口及其独占实现，而非仅隐藏界面。只隐藏会留下无法授权和解除异常状态的旧接口；同时删除历史录制超出本轮确认范围。

退役 `novaterm_list_commands`、`novaterm_execute_command`、`novaterm_run_command`、`novaterm_run_script` 四个工具。它们不再被发现、解码或分派，已有客户端调用必须明确失败，不能静默改成权限更宽的新终端输入。现行工具数由30变为26，保留工具的参数和权限边界不变。

删除主界面旧诊断/脚本/交互命令授权、旧权限开关、执行记录和结果、人工确认结束及解除目标暂停区域。删除对应生产服务接线和无其他消费者的旧实现；仍用于现行Session生命周期、连接就绪判定或配置读取的共用设施不为机械删名而重写。

保留客户端下拉选择与身份、独立令牌和授权；添加、移除、轮换令牌移到“管理客户端…”次级对话框。首次没有客户端时仍能创建；删除当前客户端后不自动把其授权赋给其他客户端；打开文件授权子窗口期间切换身份仍失效。

主界面保留开关/端点、客户端选择、复制接入配置、接管会话、当前会话读取/完整输入/提权/清空、保存目标及文件资源授权。提示文字对应现行路径，去掉旧接口与旧确认说明。保留原Qt Widgets/Ela风格、中文及翻译机制，不创建新执行器。
