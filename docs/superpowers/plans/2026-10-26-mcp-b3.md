# MCP B3/B3a Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for isolated components and parallel agents for independent domains. No commits, pushes or real devices.

**Goal:** 在既有 SSH/UART 输入与观察上交付有界文本等待和可恢复长任务入口。

**Architecture:** 日志/屏幕来源、缓存代际与输入仲裁保持现有 owner。独立等待状态只保存匹配尾部与位置；任务索引只保存 Controller 的关联和有界事实，输入仍经 TerminalInteraction。

**Tech Stack:** C++17 / Qt 6.8.3 / Windows MSVC Ninja.

**Spec:** `docs/architecture/stages/P8_AI_MCP_Interface/06_Terminal_Workflow_Extensions.md` §2/3 及本轮用户要求。

## Global Constraints

- 保留十三工具及旧九项 ToolRequest 联合；新工具在协议组合层追加。
- 不恢复 P4/P1 原型，不实施 B3b；不连接设备、不提交/推送。
- 只使用原有缓存/Controller/Arbiter，取消读取零设备写入。
- UART 无可信完成证据时退出码为空，人工接管后旧停止零写入。

## Review Focus

- 旧 PASS、页间 UTF-8 和硬换行不得产生错误命中。
- 续扫匹配状态必须与客户端、grant、epoch、generation 绑定并有期限。
- 启动受理后 RPC 断流不能重输；原 operationId 精确重试返回同一任务。
- 人工接管后停止不能以新 inputToken 获得新命令控制。
- 超时/静默、执行完成、测试成功必须分别报告。
